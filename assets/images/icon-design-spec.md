# 旅行搭子 App 图标设计说明

## 一、设计背景

「旅行搭子」是一款 Flutter 开发的个人旅游 Android 应用，核心功能包括旅行时间线、AI 对话做攻略、攻略全生命周期管理、图文旅行日记。

**品牌关键词**：清新、轻松、智能、旅行感

**主题色调**：
| 色彩名 | 色值 | 用途 |
|-------|------|------|
| 海洋蓝 | `#2196F3` | 主色（Primary） |
| 珊瑚橙 | `#FF7043` | 强调色（Accent） |
| 薄荷绿 | `#4CAF50` | 辅助色（Tertiary） |
| 浅暖灰 | `#FAFAFA` | 背景色 |

---

## 二、需要生成的图标总表

### 优先级说明
- **P0 - 必须设计**：品牌标识 + 用户最高频感知的图标
- **P1 - 建议设计**：核心交互中的功能图标
- **P2 - 可选设计**：低频功能图标，可用图标库替代

---

### 2.1 App 主图标（P0）

| 编号 | 名称 | 输出规格 | 说明 |
|------|------|---------|------|
| L-01 | 应用主图标 `ic_launcher` | 1024×1024 px 原图，自动适配 5 个密度 | 桌面图标，代表「旅行搭子」品牌 |

**设计要求**：
- 体现旅行 + 智能助手的融合感
- 适配圆形/圆角方形裁切（Android 自适应图标）
- 主色建议使用海洋蓝 `#2196F3` 或其渐变色
- 避免过多细节，小尺寸下需清晰可辨

---

### 2.2 底部导航栏图标（P0）

共 4 个 Tab，7 个图标状态：

| 编号 | Tab | 未选中态 | 选中态 | 语义 |
|------|-----|---------|-------|------|
| N-01 | 首页 | `timeline_unselected` | 可与未选中相同 | 旅行时间线，按时间顺序浏览 |
| N-02 | 攻略 | `map_unselected` | `map_selected` | 旅行攻略规划与管理 |
| N-03 | AI | `chat_unselected` | `chat_selected` | AI 智能旅行助手对话 |
| N-04 | 我的 | `person_unselected` | `person_selected` | 个人中心与设置 |

**设计要求**：
- 未选中态用线框（Outlined），选中态用填充（Filled）
- 尺寸 24×24 dp，导出 48×48 px（@2x）和 72×72 px（@3x）
- 线宽统一 1.5-2px，圆角风格统一
- 选中态使用海洋蓝 `#2196F3`，未选中态使用 `#757575`

---

### 2.3 空状态 & 引导大图标（P0）

| 编号 | 名称 | 位置 | 语义 | 建议尺寸 |
|------|------|------|------|---------|
| E-01 | 暂无旅行记录 | 首页空状态 | 引导用户开始第一篇旅行日记 | 80×80 dp |
| E-02 | 暂无对话记录 | AI 对话页空状态 | 引导用户向 AI 提问 | 80×80 dp |
| E-03 | 暂无攻略 | 攻略列表页空状态 | 引导用户通过 AI 生成攻略 | 80×80 dp |

**设计要求**：
- 使用淡灰色 `#E0E0E0` 为主色，可点缀少量主色调
- 风格温暖友好，有邀请感
- 与对应页面的引导文案搭配

## 四、设计规范

### 4.1 尺寸规范

| 类型 | 设计尺寸 | 导出规格 |
|------|---------|---------|
| App 主图标 | 1024×1024 px | 48/72/96/144/192 px（5 个密度） |
| 导航栏图标 | 24×24 dp | 48×48 px（@2x）+ 72×72 px（@3x） |
| 功能图标 | 18-24 dp | 36×36 px（@2x）+ 54×54 px（@3x） |
| 空状态大图标 | 80×80 dp | 160×160 px（@2x）+ 240×240 px（@3x） |
| FAB 图标 | 24×24 dp | 48×48 px（@2x）+ 72×72 px（@3x） |

### 4.2 风格规范

| 属性 | 规范 |
|------|------|
| 风格 | 线性（Outlined）+ 填充（Filled）双态 |
| 线宽 | 1.5 - 2 px（24dp 基准下） |
| 圆角 | 统一 2px 圆角 |
| 视觉重量 | 所有图标视觉重量需平衡一致 |
| 安全区 | 图标内容不超出 20×20 dp 的安全区域（24dp 画板） |
| 导出格式 | SVG（矢量首选）或 PNG（@2x/@3x） |

### 4.3 配色规范

| 用途 | 色值 |
|------|------|
| 选中/激活态 | `#2196F3`（海洋蓝） |
| 未选中/默认态 | `#757575`（中灰） |
| 禁用态 | `#BDBDBD`（浅灰） |
| 白色背景上的图标 | 上述三色 |
| 主色背景上的图标（如 FAB） | `#FFFFFF`（纯白） |
| 强调色图标（如已完成） | `#4CAF50`（薄荷绿） |
| 警告/花费图标 | `#FF7043`（珊瑚橙） |
