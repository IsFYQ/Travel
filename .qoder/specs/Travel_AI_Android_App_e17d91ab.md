# 旅游 AI 智能推荐 Android 应用方案

## Context

用户希望开发一个个人使用的 Android 旅游应用，核心功能包括：
- **记录旅行经历**：完整记录目的地、行程、花费、照片/视频/语音、多维评分
- **AI 做攻略**：通过对话式 AI 规划行程、估算预算、生成可编辑的攻略
- **发现新目的地**：基于历史记录和偏好，AI 推荐下一个旅行地

约束条件：用户无开发经验，1-5 人使用，严格控制成本。已有腾讯 IMA 知识库（个人旅行经验数据），需双向同步。

---

## UI 设计风格

**整体风格：旅游特色风格** — 活泼、清新、有趣

| 要素 | 方案 |
|------|------|
| 配色 | 主色：海洋蓝 #2196F3 + 点缀色：珊瑚橙 #FF7043、薄荷绿 #4CAF50 |
| 背景 | 浅暖灰 #FAFAFA，卡片白色带微阴影 |
| 图标 | 旅游主题图标（飞机、背包、地图、相机、指南针等） |
| 插图 | 首页和空状态页使用清新旅游插画（如远山、海滩、城市天际线） |
| 字体 | 系统默认字体，标题稍大加粗，正文舒适行距 |
| 动效 | 轻微的过渡动画，页面切换平滑 |
| 卡片 | 圆角 12px，记录卡片展示目的地封面照 + 评分雷达图 |

**首页设计思路：**
- 顶部：旅游统计卡片（去过 X 个城市，总行程 X 天，总花费 ¥X）
- 中部：最近旅行记录（带封面图的横向滑动卡片）
- 底部：快捷入口（新增记录、问问AI、我的攻略）

## 技术栈推荐

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| **前端框架** | Flutter (Dart) | 对新手最友好的移动开发框架，文档丰富，中文社区活跃，热重载开发体验好，未来可扩展到 iOS |
| **本地存储** | SQLite + Hive | 免费，无需服务器，适合小规模个人数据 |
| **AI 服务** | DeepSeek API | 国内模型中性价比最高（百万 token 约 1-2 元），中文理解能力强，支持长上下文 |
| **知识库检索** | 本地向量搜索（基于 AI Embedding） | 将 IMA 知识库向量化存储在本地，无需额外服务器 |
| **数据同步** | 腾讯 IMA API | 旅游记录自动同步到 IMA 知识库，双向打通 |
| **后端服务** | 无（纯客户端架构） | 1-5 人使用无需后端，数据存本地，AI 调用直连 API |

## 核心功能详细设计

### 模块 1：旅游记录管理

**数据字段：**
| 类别 | 字段 |
|------|------|
| 基础信息 | 目的地、出行日期、天数、同行人数、总花费 |
| 详细记录 | 每日行程、花费明细（交通/住宿/餐饮/门票/其他）、交通方式、住宿信息 |
| 富媒体 | 照片、短视频、语音备注 |
| 多维评分 | 风景★、美食★、住宿★、交通★、性价比★（各 1-5 星） |
| 文字 | 旅行心得/总结 |

**功能：**
- 新增/编辑/删除旅游记录
- 按目的地/时间/评分筛选和搜索
- 旅游统计概览（去过多少地方、总花费、平均评分等）
- 本地存储 + 导出备份（JSON 格式）

### 模块 2：AI 智能对话

**交互方式：** 纯对话式，仅被动响应

**功能：**
- 接入 DeepSeek Chat API
- 支持多轮对话，记住上下文
- 自动注入用户旅游记录作为背景信息（RAG）
- 支持场景举例：
  - “预算 3000 元，5 天假期，推荐去哪？”
  - “我之前去云南觉得不错，有类似的地方吗？”
  - “帮我规划一个成都 3 天的行程”
- 对话历史保存，可回看

### 模块 3：攻略生成与编辑

**生成流程：**
1. 用户在对话中提出攻略需求（目的地 + 天数 + 预算）
2. AI 生成结构化行程表（每日时间线 + 景点 + 交通 + 住宿 + 餐饮）
3. 用户可一键保存为攻略
4. 保存后可手动编辑：修改内容、添加备注、调整顺序

**攻略展示格式：**
```
Day 1: 2024/10/01
  09:00 ✈️ 抵达成都双流机场
  10:30 🚕 前往锦里（打车约30元）
  11:00 🏞️ 锦里古街（免费）
  12:30 🍜 午餐：陈麻婆豆腐（约 30元/人）
  ...
  🏨 住宿：春熙路民宿（约 200元）
  💰 当日预算：~400元
```

## 模块 4：知识库管理

**数据来源：** 个人旅行经验（从腾讯 IMA 知识库迁移）

**RAG 检索流程：**
```
用户提问 → Embedding(提问) → 本地向量相似度搜索
→ 取 Top-K 相关文档 → 拼接进 Prompt → AI 生成回答
```

**功能：**
- 导入 IMA 数据（支持文本/JSON/图片描述）
- 向量化存储在本地
- 支持增量添加新经验
- 旅游记录自动同步到知识库（新增记录自动向量化）

### 模块 5：IMA 同步

**平台：** 腾讯 IMA（有 API 接口，支持笔记追加/删除/读取）

**同步策略：自动同步**
```
新增/编辑旅游记录 → 格式化为笔记内容 → 调用 IMA API 追加/更新
删除旅游记录 → 调用 IMA API 删除对应笔记
首次使用 → 从 IMA 拉取已有笔记 → 解析导入本地
```

**同步内容格式（推送到 IMA 的笔记）：**
```
标题：[目的地] YYYY-MM-DD ~ YYYY-MM-DD
内容：
  📍 目的地：成都
  📅 时间：2024/10/01 - 2024/10/03（3天）
  👥 同行：2人
  💰 总花费：¥2400
  ⭐ 评分：风景4.5 美食5.0 住宿4.0 交通3.5 性价比4.5
  📝 心得：...
  📋 每日行程：...
```

**关键设计：**
- 本地记录为主，IMA 为备份/同步目标
- 网络不可用时暂存同步队列，恢复后自动补发
- 支持冲突检测（本地修改 vs IMA 修改）
- 在"我的"→"IMA 设置"中配置 IMA API 凭证

## 页面结构与导航

**底部导航栏（4 个 Tab）：**

| Tab | 功能 | 说明 |
|-----|------|------|
| 🏠 首页 | 旅游概览 | 旅行统计、最近记录、快捷操作入口 |
| 📖 记录 | 旅游记录列表 | 增删改查、筛选、搜索、详情查看 |
| 🤖 AI | 智能对话 | 对话式交互，推荐 + 攻略生成 |
| 👤 我的 | 个人设置 | 知识库管理、IMA同步设置、数据备份、API设置、关于 |

**关键页面流程：**
```
首页 → 点击“新增记录” → 填写旅游记录表单 → 保存
首页 → 点击 AI → 对话输入 → AI 回复 → 保存攻略
AI 页 → AI 生成攻略 → 一键保存 → 进入攻略编辑页
我的 → 知识库管理 → 导入数据 / 查看已有数据
我的 → 数据备份 → 导出 JSON 到本地文件
我的 → IMA 设置 → 配置 IMA API → 开启自动同步
```

## 关键技术方案

## AI 集成方案（DeepSeek）

**API Key 管理：**
- 用户在 "我的" → "API 设置" 中输入 DeepSeek API Key
- Key 使用 flutter_secure_storage 加密存储
- 应用直接从客户端调用 DeepSeek API（无需中转服务器）
- 开发阶段：你直接告诉我 Key，我写入本地配置文件

**调用流程：**
```
用户提问 → 查询本地旅游记录 → 知识库语义检索
→ 构建 Prompt（系统提示 + 历史记录 + 检索结果 + 用户问题）
→ 调用 DeepSeek Chat API → 解析返回结果 → 展示/保存
```

### 数据安全
- DeepSeek API Key：flutter_secure_storage 加密存储
- IMA API 凭证：同样加密存储
- 本地数据使用 SQLite（可选加密扩展）
- 不上传任何个人数据到第三方（仅 AI 对话内容发送给 DeepSeek，旅游记录同步到 IMA）

## 备选方案与建议

1. **如果 DeepSeek 不合适**：可替换为通义千问（阿里云）或 Kimi（月之暗面），接口格式类似
2. **如果需要多人同步**：后续可加入 Supabase（免费额度足够 5 人用）
3. **如果想更简单起步**：可先做一个 Web 版（用 Flutter Web），不需要安装
4. **IMA 知识库迁移**：建议导出为 JSON/Markdown 格式，方便后续处理
